# proto V2-V3 补全 + FlatBuffers 适配器 + 节点级转换/格式化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 RTTI 库的 proto 支持补全至 V2-V3 全语法(含 zigzag/map/oneof/import/reserved/extensions 按官方语义),新增 FlatBuffers 格式适配器(.fbs 文本解析 + wire 编解码),实现跨格式节点级转换(locate/node_as/to_node)与字符串格式化(日期/数字/反射驱动),全部以官方 protoc/flatc 工具生成 fixtures 逐字节对拍保证绝对正确;保持静态库+头文件形态,新增实现非模板编入 src/*.cpp;剥离矩阵扩至 6 门 64 组合;README 双语对称 + examples 接口全覆盖。

**Architecture:** 解析器/编解码器主体做成非模板放 `src/*.cpp`(静态库 `rtti` 吸收),头文件只留模板壳(schema<T> 注册、converter 特化、typed 桥)。官方 protoc 36.2 / flatc 25.12.19 已部署于 `$env:USERPROFILE\.rtti-tools`,生成 `.proto`/`.fbs` 的 wire fixtures 与生成头作为测试夹具提交仓库,测试读取 fixtures 与 rtti 输出逐字节/逐字段对拍。

**Tech Stack:** C++17、MSVC 2022（/W4 /permissive- /Zc:preprocessor，零警告）、CMake（"Visual Studio 17 2022" -A x64）、官方 protoc 36.2 + flatc 25.12.19(fixtures 生成、开发期对拍),GCC/Clang 兼容静态预判。

**Spec:** `docs/superpowers/specs/2026-10-07-proto-v2v3-flatbuffers-design.md`

## Review Focus

- **官方 wire 字节差异**:用户传入 protoc/flatc 官方产出的二进制,库必须逐字节等价或以规范允许等价形式读取回写。→ T-P1/T-F1 fixtures 对拍测试。
- **未知字段/扩展**:wire 上遇到 schema 未声明的字段号(proto extensions 未注册应保留跳过、注册应答解析;flatbuffers 未知字段跳过)。→ T-P2/T-F1 固化。
- **深度/长度恶性输入**:深嵌套消息(.proto/.fbs 解析嵌套、wire 嵌套)与超长 varint/length→too_deep/invalid,不崩溃。→ T-P1/T-F1 探针。
- **root 对齐/flatbuffer 偏移陷阱**:flatbuffers vtable slot 缺省(default)、对齐(1/2/4/8)、root offset 指向尾部,手工或半官方字节易错。→ T-F1 官方 fixtures 对拍覆盖对齐与缺省。
- **节点路径不存在**:locate 对缺失键/越界索引/深层断链返回 error_code(§0),locate 目标节点后再 to_node 替换子树不破坏原文档其余部分。→ T-L 全失败路径。
